# NOIR Athletic Club — Luxury Gym Website Demo

A responsive, multi-section commercial gym website concept with a muted luxury palette:
- charcoal / warm black
- stone / ivory
- taupe / muted bronze
- restrained photography and editorial typography

## Run
Open `index.html` in a browser. For deployment, upload the files to a static hosting provider such as Vercel or Netlify.

## Important demo limitations
- The forms currently show a local confirmation message; they do not send or store enquiries.
- The AI coach is a scripted UI demonstration; it is not connected to an AI model.
- Membership plans, prices, addresses, hours and statistics are placeholders.
- Remote Unsplash photos and Google Fonts require internet access.
- Replace demo copy, photos, branding, contact details and pricing with client-approved assets before commercial deployment.

## Suggested production integrations
1. Secure backend/database for enquiries and bookings.
2. Transactional email provider for confirmation and gym notifications.
3. SMS provider where needed.
4. AI API behind a server-side endpoint, with reviewed gym knowledge and privacy controls.
5. Admin dashboard and spam protection if required.
